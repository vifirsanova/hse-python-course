## Жадный алгоритм

Алгоритм, который на каждом шаге делает локально оптимальный
выбор в надежде, что итоговое решение окажется глобально
оптимальным.

- решение строится пошагово;
- назад не возвращаемся;
- ранее принятые решения не пересматриваются.

## Два ключевых свойства

| Свойство | Описание |
|----------|----------|
| Жадный выбор | существует локально оптимальный выбор, приводящий к глобально оптимальному |
| Оптимальная подструктура | оптимальное решение содержит оптимальные решения подзадач |

Если хотя бы одно не выполняется — жадный алгоритм может ошибиться.

## Сравнение подходов

| Подход | Идея | Пример |
|--------|------|--------|
| Жадный | локально оптимальный выбор | размен монет, интервалы |
| Динамическое программирование | запоминание подзадач | рюкзак, редакционное расстояние |
| Полный перебор | проверка всех вариантов | задача коммивояжёра |

Жадный обычно `O(n log n)` или `O(n)` против экспоненциального перебора.

## Размен монет

Условие: сумма S и набор номиналов. Выдать минимальным
количеством монет.

Жадная стратегия:

1. взять самую крупную монету, не превышающую остаток;
2. вычесть её;
3. повторять до нуля.

```python
def min_coins(amount, coins):
    coins.sort(reverse=True)
    count = 0
    for coin in coins:
        while amount >= coin:
            amount -= coin
            count += 1
    return count if amount == 0 else -1
```

Сложность: `O(k log k + n)`.

Жадность оптимальна для стандартных номиналов (1, 5, 10, 50, 100).
Для произвольных (1, 3, 4) может ошибиться.

## Выбор интервалов

Условие: выбрать максимальное количество непересекающихся
интервалов.

Стратегия:

1. отсортировать по времени окончания;
2. брать интервал, если он начинается не раньше окончания
   предыдущего.

```python
def max_intervals(intervals):
    intervals.sort(key=lambda x: x[1])
    count = 0
    last_end = float("-inf")
    for start, end in intervals:
        if start >= last_end:
            count += 1
            last_end = end
    return count
```

Сложность: `O(n log n)`.

## Дробный рюкзак

Условие: рюкзак вместимостью W, предметы с весом wi и
стоимостью vi. Можно брать части.

Стратегия:

1. вычислить удельную стоимость vi/wi;
2. сортировать по убыванию;
3. брать предметы, пока есть место;
4. последний — частично.

```python
def fractional_knapsack(capacity, items):
    items.sort(key=lambda x: x[1] / x[0], reverse=True)
    total = 0.0
    for weight, value in items:
        if capacity >= weight:
            total += value
            capacity -= weight
        else:
            total += value * (capacity / weight)
            break
    return total
```

Сложность: `O(n log n)`.

Целочисленный рюкзак жадным не решается — нужна динамика.

## Минимальное число платформ

Условие: даны времена прибытия и отправления поездов.
Определить минимальное число платформ.

Идея: отсортировать события: прибытие +1, отправление -1.
Пройти, поддерживая текущее число занятых платформ и максимум.

```python
def min_platforms(arrivals, departures):
    events = [(t, 1) for t in arrivals] + \
             [(t, -1) for t in departures]
    events.sort()
    current = 0
    best = 0
    for _, delta in events:
        current += delta
        best = max(best, current)
    return best
```

Сложность: `O(n log n)`, память `O(n)`.

При равном времени прибытия и отправления отправление
обрабатывается раньше прибытия.
