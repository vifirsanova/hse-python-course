## Алгоритм

Конечная последовательность однозначно заданных действий,
преобразующая входные данные в результат.

## Свойства алгоритма

| Свойство | Описание |
|----------|----------|
| Определённость | каждая команда однозначна и понятна |
| Конечность | завершается за конечное число шагов |
| Результативность | приводит к проверяемому результату |
| Дискретность | состоит из отдельных шагов |
| Массовость | применим к классу входных данных |
| Выполнимость | каждая команда элементарна и выполнима |

## Оценка сложности циклов

| Ситуация | Сложность |
|----------|-----------|
| Один цикл по n элементам | `O(n)` |
| Вложенные циклы | `n * n = O(n^2)` |
| Последовательные фрагменты | `O(n) + O(n^2) = O(n^2)` |

Оставляется слагаемое более высокого порядка.

## Основные классы сложности

| Обозначение | Название |
|-------------|----------|
| `O(1)` | постоянное |
| `O(log n)` | логарифмическое |
| `O(n)` | линейное |
| `O(n log n)` | типичная эффективная сортировка |
| `O(n^2)` | квадратичное |

## Бинарный поиск

Для отсортированного списка:

1. смотрим на центральный элемент;
2. сравниваем с искомым;
3. отбрасываем половину;
4. повторяем для оставшейся половины.

Сложность: `O(log n)`.

## Откуда берётся O(n log n)

1. задача делится на несколько уровней;
2. на каждом уровне обрабатывается суммарно n элементов;
3. уровней `log n`.

```
n + n + ... + n = n log n
     log n раз
```

## Пример: проверка дубликатов

Медленное решение:

```python
def has_duplicates(nums):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] == nums[j]:
                return True
    return False
```

`T(n) = O(n^2)`, `S(n) = O(1)`.

Улучшенное решение:

```python
def has_duplicates(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False
```

`T(n) = O(n)`, `S(n) = O(n)`.

## Тесты

```python
assert has_duplicates([]) is False
assert has_duplicates([1, 2, 1]) is True
```

Запуск через `assert` или `pytest`
