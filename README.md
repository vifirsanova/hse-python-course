## Как начать работу

### 1. Создайте fork репозитория

Fork — это копия учебного репозитория в вашем аккаунте GitHub.

1. Откройте исходный репозиторий курса.
2. Нажмите кнопку **Fork**.
3. В поле **Owner** выберите свой аккаунт.
4. При необходимости измените название репозитория.
5. Нажмите **Create fork**.

После этого в вашем аккаунте появится собственная копия репозитория.

---

### 2. Склонируйте fork на компьютер

```bash
git clone https://github.com/<ваш-username>/<название-репозитория>.git
```

Перейдите в папку проекта:

```bash
cd <название-репозитория>
```

---

### 3. Установите зависимости

В папке репозитория выполните:

```bash
pip install -r requirements.txt
```

Если команда `pip` не найдена, попробуйте:

```bash
python -m pip install -r requirements.txt
```

На macOS и Linux может понадобиться:

```bash
python3 -m pip install -r requirements.txt
```

---

### 4. Выполняйте задания

Решения размещайте в соответствующих папках:

```text
week_01_intro/homework/homework_base/tasks.py
week_01_intro/homework/homework_advanced/tasks.py
```

Для работы на паре используйте файлы:

```text
week_01_intro/classwork_base/topics.md   # список задач для базового уровня
week_01_intro/classwork_advanced/topics.md   # список задач для продвинутого уровня
```

Реализуйте функции, отмеченные комментарием:

```python
# TODO
```

Не изменяйте тесты, если это не разрешено в условии задания.

---

### 5. Отправляйте решение на GitHub

После выполнения задания:

```bash
git status
git add .
git commit -m "Implement week 1 homework"
git push
```

Сообщение коммита должно кратко описывать изменения.

Примеры:

```bash
git commit -m "Implement week 1 base tasks"
git commit -m "Fix recursion solution in week 3 advanced"
git commit -m "Add sorting algorithms week 4"
```

Проверьте, что изменения появились в вашем fork на GitHub.

## Домашние задания

Домашнее задание состоит из двух уровней:

| Уровень | Описание | Формат |
| --- | --- | --- |
| **Базовый** | Типовые задачи на отработку синтаксиса | `homework_base/tasks.py` |
| **Продвинутый** | Кейсы на поиск ошибок, оптимизацию, написание алгоритма по схеме, полное решение с нуля | `homework_advanced/tasks.py` |

**Базовый уровень** обязателен для всех.  
**Продвинутый уровень** — для студентов, которые имеют опыт программирования.

## Classwork

На каждом занятии студенты решают задачи в паре с преподавателем:

| Уровень | Описание |
| --- | --- |
| **Базовый** | Студенты получают готовый алгоритм и дописывают 2–3 строки кода. |
| **Продвинутый** | Реализация алгоритма с нуля по ТЗ или поиск ошибок в готовом коде. |

Также задачи делятся по использованию ИИ:
- `ai_allowed` — можно использовать ИИ как основной инструмент.
- `ai_forbidden` — строго без ИИ (отмечено в условии задачи).

## Стартовое домашнее задание (не оценивается)

Цель — подготовить рабочее окружение. Задание **не влияет** на итоговую оценку.

1. Установите **Python** (версия 3.10 или выше).
2. Установите **Git** и настройте глобальные параметры:
   ```bash
   git config --global user.name "Ваше Имя"
   git config --global user.email "your_email@example.com"
   ```
3. Установите **IDE** на выбор:
   - PyCharm (Community Edition) — рекомендуется.
   - Visual Studio Code + расширение Python.
   - Любой другой редактор.
4. Создайте папку `hello_world`, внутри файл `main.py`:
   ```python
   print("Hello, world!")
   ```
5. Инициализируйте Git, сделайте первый коммит:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```
6. Пришлите ссылку на публичный репозиторий или файл `main.py` преподавателю.

Если возникли проблемы:
- Напишите в Telegram или на почту.
- Подготовьте вопрос по ДЗ для разбора на паре.
- Если проблемы с ПО — подойдите индивидуально перед занятием.
