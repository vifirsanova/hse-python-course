# Среда разработки для Python

Для курса понадобится:

1. Python
2. IDE или редактор
3. терминал

Этот гайд поможет вам установить среду программирования **PyCharm** или **Visual Studio Code**, чтобы все было под рукой.

---

## Вариант 1. PyCharm

### Скачать

Официальная страница загрузки:

https://www.jetbrains.com/pycharm/download/

PyCharm работает на:

- Windows;
- macOS;
- Linux (также Code-OSS).

Версия PyCharm Community бесплатная, её и ищем на странице загрузки.

### Установка

1. Откройте страницу загрузки.
2. Скачайте установщик для своей операционной системы.
3. Запустите установщик.
4. Оставьте настройки по умолчанию.
5. Запустите PyCharm.
6. Выберите **Open** и откройте папку с проектом.

### Создание проекта

При создании нового проекта:

1. Выберите папку проекта.
2. Укажите установленный Python (если Python не установлен, скачиваем на python.org по инструкции на сайте).
3. Оставьте включённым виртуальное окружение, если PyCharm предлагает его создать.
4. Создайте файл с расширением `.py`.

Например:

```python
print("Hello, Python!")
```

Запустите файл кнопкой с треугольником **Run**.

### Установка зависимостей (понадобится позже)

Откройте встроенный терминал PyCharm и выполните:

```bash
pip install -r requirements.txt
```

### Запуск тестов (понадобятся позже)

В терминале PyCharm:

```bash
pytest seminar*/tests/ -v
```

Или запустите отдельный тест:

```bash
pytest seminar1/tests/test_task1_duplicates.py -v
```

### Плюсы PyCharm

- поддержка Python;
- подсказки и автодополнение;
- отладка;
- встроенная работа с Git;
- поддержка виртуальных окружений

### Минусы PyCharm

- занимает много места;
- интерфейс перегружен;
- первый запуск может быть медленным;
- установка пакетов и поиск Python иногда лагает

## Вариант 2. Visual Studio Code

### Скачать

Официальная страница загрузки:

https://code.visualstudio.com/download

Документация по Python:

https://code.visualstudio.com/docs/languages/python

### Установка

1. Скачайте Visual Studio Code для своей операционной системы.
2. Установите программу.
3. Откройте VS Code.
4. Откройте раздел **Extensions**.
5. Установите расширение **Python** от Microsoft.
6. При необходимости установите расширение **Python Debugger**.

Важно: расширение Python не содержит сам Python. Интерпретатор Python устанавливается отдельно.

Скачать Python:

https://www.python.org/downloads/

### Выбор интерпретатора

Откройте палитру команд:

- Windows/Linux: `Ctrl + Shift + P`;
- macOS: `Cmd + Shift + P`.

Введите:

```text
Python: Select Interpreter
```

Выберите установленную версию Python или виртуальное окружение проекта.

### Запуск программы

Создайте файл `hello.py`:

```python
print("Hello, Python!")
```

Запустите его одним из способов:

- нажмите кнопку **Run Python File**;
- нажмите правой кнопкой мыши по файлу и выберите запуск в терминале;
- выполните в терминале:

```bash
python hello.py
```

На macOS и Linux команда может выглядеть так:

```bash
python3 hello.py
```

### Установка зависимостей и запуск тестов

Откройте встроенный терминал VS Code:

```bash
pip install -r requirements.txt
pytest seminar*/tests/ -v
```

### Плюсы VS Code

- быстро запускается;
- занимает меньше памяти;
- поддерживает Python через расширения;
- удобно работать с Git и терминалом;
- подходит для разных языков программирования;
- много ИИ-возможностей

### Минусы VS Code

- необходимо самостоятельно установить Python;
- часть функций нужно настраивать вручную;
- для начинающего пользователя интерфейс может быть менее очевидным

---

Рекомендую установить и то, и другое, и далее работать с той IDE, которая вам приятнее по личным соображениям.

---

## Минимальная проверка установки

Создайте файл `hello.py`:

```python
print("Hello, Python!")
```

Запустите его. В терминале должен появиться результат:

```text
Hello, Python!
```
