В папке `instructions` вы найдете стартовые инструкции для настройки среды программирования, git и работе с Markdown. К первому семинару убедитесь, что у вас

1. Установлена среда программирования PyCharm / VS Code или "в боевой готовности" Python, терминал и редактор
2. Установлен и настроен git. Инструкция поможет вам разобраться с первым запуском, но если что-то не получилось, не беда! Подготовьте вопросы преподавателю, их можно направить мне в личные сообщения или на почту vfirsanova@hse.ru
3. Есть понимание работы с языком разметки Markdown. Он пригодится нам для работы с README-файлами, а также планированием проектов во время командной проектной работы
